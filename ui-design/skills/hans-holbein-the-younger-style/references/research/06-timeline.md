# Hans Holbein the Younger：生涯、作品与研究时间线

## 生涯与作品

| 日期 | 事件 / 作品 | 证据与视觉意义 |
|---|---|---|
| 1497 年冬至 1498 年 | 生于奥格斯堡；确切生日不存。 | **【一手/官方】** 父亲 Hans Holbein the Elder 的作坊提供早期训练。[National Gallery artist page](https://www.nationalgallery.org.uk/artists/hans-holbein-the-younger)；[British Museum biography](https://www.britishmuseum.org/collection/term/BIOG31810) |
| 1515 | 与兄长 Ambrosius 到巴塞尔。 | **【一手/官方】** 进入人文主义出版、书籍插图、肖像与城市委托环境。[Kunstmuseum Basel](https://kunstmuseumbasel.ch/en/exhibitions/2006/hans-holbein-the-younger) |
| 1516 | Jacob Meyer 与 Dorothea Meyer 双肖像；学校教师招牌等早期图文作品。 | **【一手/官方】** 已能在肖像、文字和公共功能之间切换。[British Museum biography](https://www.britishmuseum.org/collection/term/BIOG31810) |
| 1517–19 | 在 Lucerne 参与 Jacob von Hertenstein 宅邸壁画，往返瑞士城市。 | **【一手/官方】** 早期大尺度建筑装饰经验；作品多已失。[British Museum biography](https://www.britishmuseum.org/collection/term/BIOG31810) |
| 1519–20 | 1519 年加入巴塞尔画家行会，次年成为巴塞尔市民。 | **【一手/官方】** 从流动作坊成员进入城市职业制度。[British Museum biography](https://www.britishmuseum.org/collection/term/BIOG31810) |
| 1519 | *Portrait of Bonifacius Amerbach*。 | **【一手/官方】** 人文主义者肖像、题记与小型板画的早期成熟案例。[Getty exhibition checklist/context](https://www.getty.edu/art/exhibitions/holbein/index.html) |
| 1521–22 | *The Dead Christ in the Tomb*；Basel Council Chamber 与 Haus zum Tanz 壁画。 | **【一手/官方】** 宗教身体、极端横向格式与公共壁画并行。[Kunstmuseum Basel, Old Masters](https://kunstmuseumbasel.ch/en/collection/alte-meister)；[British Museum biography](https://www.britishmuseum.org/collection/term/BIOG31810) |
| 1523 | 为 Erasmus 制作多种肖像；继续书籍和页边图设计。 | **【一手/官方】** likeness 成为跨国学者网络中可复制和馈赠的公共形象。[The Met, *Erasmus*](https://www.metmuseum.org/art/collection/search/459080) |
| 1523–24 | 赴法国活动；寻求更广阔宫廷市场。 | **【一手/官方】** 具体行程与目的仍不完全清楚。[Kunstmuseum Basel](https://kunstmuseumbasel.ch/en/exhibitions/2006/hans-holbein-the-younger)；[National Gallery artist page](https://www.nationalgallery.org.uk/artists/hans-holbein-the-younger) |
| 1524–25 | 设计“死亡之舞”木刻组版，Hans Lützelburger 刻制。 | **【一手/官方】** 极小尺度中以轮廓、职业属性和连续叙事压缩社会秩序；书籍版 1538 年后发行。[British Museum, series woodcut](https://www.britishmuseum.org/collection/object/P_1895-0122-809) |
| 1526 | 创作 *Darmstadt Madonna*；持 Erasmus 介绍赴英。 | **【一手/官方】** 宗教委托与跨国肖像网络在同年并行。[Kunstmuseum Basel, Darmstadt Madonna](https://kunstmuseumbasel.ch/en/21)；[The Met, *Erasmus*](https://www.metmuseum.org/art/collection/search/459080) |
| 1526–28 | 第一次英格兰时期：Thomas More、Guildford 圈肖像和英法外交庆典装饰。 | **【一手/官方】** More 家庭群像原作已失，构图稿与个别肖像稿存世。[Royal Collection Trust, court overview](https://www.rct.uk/collection/exhibitions/holbein-at-the-tudor-court/the-queens-gallery-buckingham-palace/hans-holbein) |
| c. 1526–28 | *A Lady with a Squirrel and a Starling (Anne Lovell?)*。 | **【一手/官方】** 松鼠较晚加入并改变双臂；身份与椋鸟 rebus 仍带问号。[National Gallery catalogue](https://www.nationalgallery.org.uk/paintings/catalogues/foister-2024/a-lady-with-a-squirrel-and-a-starling-anne-lovell) |
| 1527 | *Sir Thomas More* 及 More 家庭群像设计。 | **【一手/官方】** 衣领、职位、书籍与家庭关系形成早期英格兰身份系统；完整群像仅从稿本与复制可知。[Royal Collection Trust, court overview](https://www.rct.uk/collection/exhibitions/holbein-at-the-tudor-court/the-queens-gallery-buckingham-palace/hans-holbein) |
| 1528 | 返回巴塞尔；继续市政壁画，制作妻子 Elsbeth 与两个孩子的家庭肖像。 | **【一手/官方】** 对自家人物的处理与宫廷肖像并存，但不可据此诊断家庭关系。[Kunstmuseum Basel](https://kunstmuseumbasel.ch/en/exhibitions/2006/hans-holbein-the-younger) |
| 1529 | 巴塞尔宗教改革改变宗教图像市场。 | **【权威二手】** 需求变化是再次赴英的重要背景之一，不是唯一动机。[Royal Collection Trust, court overview](https://www.rct.uk/collection/exhibitions/holbein-at-the-tudor-court/the-queens-gallery-buckingham-palace/hans-holbein) |
| 1532 | 第二次赴英并定居伦敦；开始斯蒂尔亚德商人组像。 | **【一手/官方】** *Georg Gisze*、*Hans of Antwerp* 等以信件、印章、题记和材料建立跨国商人身份。[Metropolitan Museum Journal](https://resources.metmuseum.org/resources/metpublications/pdf/Holbeins_Portraits_of_the_Steelyard_Merchants_The_Metropolitan_Museum_Journal_v_14_1979.pdf)；[Royal Collection Trust, conservation](https://www.rct.uk/collection/conservation/conserving-holbeins-hans-of-antwerp) |
| 1532–33 | *Thomas Cromwell*；*Derich Born*。 | **【一手/官方】** 前者用行政文件构造职务，后者用拟刻拉丁题记宣示 likeness。[Getty](https://www.getty.edu/news/holbein-capturing-character-in-renaissance/)；[Royal Collection Trust, Derich Born](https://www.rct.uk/collection/stories/holbein-in-the-royal-collection/derich-born) |
| 1533 | *The Ambassadors*；*Robert Cheseman*；参与 Anne Boleyn 加冕相关装饰。 | **【一手/官方】** 同年横跨法国外交双人像、英格兰宫廷职位肖像与临时庆典。[National Gallery catalogue](https://www.nationalgallery.org.uk/paintings/catalogues/foister-2024/the-ambassadors)；[Mauritshuis](https://www.mauritshuis.nl/ontdek-collectie/kunstwerken/276-portret-van-robert-cheseman-1485-1547)；[Royal Collection Trust](https://www.rct.uk/collection/exhibitions/holbein-at-the-tudor-court/the-queens-gallery-buckingham-palace/hans-holbein) |
| 1533，《大使们》内部时间 | 仪器读数可能落在 4 月、7 月或 8 月，互不统一。 | **【一手/官方】** 不能把画面锁定为单一纪念日；不一致可能来自研究复用、无关紧要或有意失谐。[National Gallery catalogue](https://www.nationalgallery.org.uk/paintings/catalogues/foister-2024/the-ambassadors) |
| 1535–43 | Simon George of Cornwall (?) 圆形侧面像。 | **【一手/官方】** tondo、康乃馨与 Leda 帽饰指向求偶与古典文化，姓名仍不完全确定。[Städel Museum](https://sammlung.staedelmuseum.de/en/work/portrait-of-simon-george-of-cornwall) |
| 至迟 1536 年 9 月 | 获任 King’s Painter，年薪 30 英镑。 | **【一手/官方】** 是数名王室画家之一，并非薪酬最高。[Royal Collection Trust](https://www.rct.uk/collection/exhibitions/holbein-at-the-tudor-court/the-queens-gallery-buckingham-palace/hans-holbein) |
| 1536–37 | Jane Seymour 肖像稿与成画。 | **【一手/官方】** 稿本被加长、划分不同格式，成为可复制的宫廷 likeness 资产。[Royal Collection Trust, Jane Seymour](https://www.rct.uk/collection/stories/holbein-in-the-royal-collection/jane-seymour) |
| 1537 | Whitehall Palace Privy Chamber 王朝壁画。 | **【一手/官方】** 正面全身 Henry VIII 形象影响深远；原作 1698 年毁于火灾，依靠卡通与复制存续。[Royal Collection Trust, Whitehall copy](https://www.rct.uk/collection/stories/royal-portraiture/henry-vii-elizabeth-of-york-henry-viii-and-jane-seymour) |
| 1538 年 3 月 | 赴布鲁塞尔为 Christina of Denmark 取貌。 | **【一手/官方】** 唯一有明确记录的坐姿约三小时；素描作为跨海外交代理，现存大板画在伦敦完成的可能性高。[National Gallery catalogue](https://www.nationalgallery.org.uk/paintings/catalogues/foister-2024/christina-of-denmark-duchess-of-milan) |
| 1538 | “死亡之舞”41 幅书籍版在 Lyon 出版；据 Royal Collection 记录又曾短暂回巴塞尔。 | **【一手/官方】** 设计、刻制、出版时间必须区分。[British Museum, 1538 book](https://www.britishmuseum.org/collection/object/P_1904-0206-80)；[Royal Collection Trust](https://www.rct.uk/collection/stories/holbein-in-the-royal-collection) |
| 1538–39 | *Edward VI as a Child*，1539 年新年赠给 Henry VIII。 | **【一手/官方】** 正面姿势、权杖和拉丁诗服务继承叙事；可能是画家赠礼而非王命。[NGA](https://www.nga.gov/artworks/71-edward-vi-child)；[Royal Collection Trust](https://www.rct.uk/collection/exhibitions/holbein-at-the-tudor-court/the-queens-gallery-buckingham-palace/hans-holbein) |
| 1539–40 | *Anne of Cleves*。 | **【一手/官方】** 处于婚姻外交语境；Louvre 修复后从头带与胸针辨认婚约线索，作品是在 Düren 当面完成还是伦敦据稿完成仍在讨论。[Louvre](https://www.louvre.fr/en/portrait-of-anne-of-cleves-by-hans-holbein-the-younger) |
| 1542–43 | 晚期宫廷素描、微型像与自画像时期。 | **【一手/官方】** 许多坐者身份后来发生变更或仍不确定，NPG 记录大量复制与工作室版本。[NPG Holbein record](https://www.npg.org.uk/collections/search/person/mp07116/hans-holbein-the-younger) |
| 1543 年 10 月 7 日至 11 月 29 日之间 | 在伦敦去世；10 月 7 日立遗嘱，11 月 29 日文件称其已故。 | **【权威二手 + 一手档案】** 确切死日和死因不应写死；遗嘱关注债务与受抚养者。[Cambridge Core, will article](https://www.cambridge.org/core/journals/archaeologia/article/idiscovery-of-the-will-of-hans-holbein/B21E517CEF33532F4AF3EC02E6C1C7CC)；[NPG](https://www.npg.org.uk/collections/search/person/mp07116/hans-holbein-the-younger) |

## 阶段演化摘要

- **【研究推断】1515–25：** 在巴塞尔把线性轮廓、印刷压缩、人文主义题记、宗教身体与城市壁画合成多媒介基础。
- **【研究推断】1526–32：** 通过 Erasmus–More 网络学习英格兰宫廷、家庭与贵族肖像的用途，并在巴塞尔和伦敦之间重新配置职业。
- **【研究推断】1532–36：** 斯蒂尔亚德商人、法国使节和英格兰官员共同推动“身份可读 + 表面精确”的成熟系统。
- **【研究推断】1536–43：** 王室职位扩大尺度、复制与外交功能；同时保留微型像、个人徽记、求偶肖像和复杂歧义。
- **【权威二手】1543 以后：** 素描、复制、火灾、收藏题签、修复和再归属持续改变“霍尔拜因”所指的作品边界。

## 明确的不确定项

- 出生的确切日期。
- 若干法国与意大利行程细节。
- Anne Boleyn 等皇家素描的部分身份。
- 《大使们》原始悬挂高度、进入路径、全部顾问与每件对象的确切意义。
- 变形骷髅使用的唯一制作法。
- 1543 年确切死日与死因。
- 2026 年不存在“本人最新动态”；最近条目只涉及修复、目录与学术研究。
