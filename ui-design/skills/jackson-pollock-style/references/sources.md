# Jackson Pollock Phase 1 Sources

调研截止：2026-08-03。共 25 个去重来源；均为一手档案、艺术家/遗产机构、主要博物馆、同行评议论文或大学学术库。这里的“官方”表示馆藏/档案/遗产机构记录，不表示其解释是唯一结论。

## 可信度口径

- **A（一手/官方）**：Pollock 本人文本或录音的档案记录、同期书信、作品本体技术检查、摄影/电影原始记录、官方工作室遗存。
- **B（权威二手）**：主要博物馆策展与馆藏研究、同行评议论文、大学出版社/学术库论文。
- **C（研究推断）**：本研究基于 A/B 证据作出的视觉或当代设计推断；C 不作为独立来源。
- 同一博物馆的不同页面只有在其证据功能不同（原始文献汇编、技术研究、作品记录等）时才分别保留。

## 补充争议记录（不计入 24 个主来源）

- 【一手/官方】Pollock-Krasner Foundation 明确表示不做鉴定或归属建议：https://www.pkf.org/about/resources/ 。这意味着本研究不能把“像 Pollock”转化为归属判断。
- 【权威二手】关于分形能否认证的反例研究：Katherine Jones-Smith 与 Harsh Mathur, PubMed/Nature record, https://pubmed.ncbi.nlm.nih.gov/17136047/ 。它反驳“分形是单一可靠指纹”的强主张；分形最多是多证据系统中的一项。

## 覆盖与占比

- 主来源总数：25。
- A 类或含 A 类实物/档案证据：13/25（52.0%）。
- A 类 + 主要博物馆/遗产机构 + 同行评议/大学学术库：25/25（100%）。
- 本人可核验的公开声音集中在短声明、问卷、一次广播访谈、少量书信与晚期访谈；没有可与当代艺术家相比的长篇自著或大量未经编辑长访谈。

## 使用边界

- 【研究推断】这些来源支撑的是视觉原则研究，不授权复制具体作品构图、署名式滴洒图案或宣称“生成 Pollock 原作”。
- 【研究推断】照片与电影既是过程证据，也是经过机位、表演、拍摄条件与剪辑塑造的媒介对象；不能当成无中介的工作室直播。
- 【研究推断】材料科学能回答“用了什么、先后如何、物理条件为何”，不能独自回答作品意义或真伪；归属仍需 provenance、connoisseurship、技术分析与目录记录共同判断。
