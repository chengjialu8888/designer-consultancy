# 06｜关键时间线、系列演化与归属争议

> 历史人物说明：Lucio Fontana 于 1968 年去世。本时间线不编造“最近动态”；1968 年后的节点仅记录档案、重建和研究史。

| 年份 | 作品/事件事实 | 方法演化与证据判断 |
|---|---|---|
| 1899 | 【一手/官方】2 月 19 日生于阿根廷 Rosario，父母为意大利裔；父亲 Luigi 是雕塑家。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】其归属应至少写作 Argentine-Italian；单写“意大利艺术家”会遮蔽 Buenos Aires 的理论生成。 |
| 1906–1921 | 【一手/官方】在意大利受教育、进入父亲工坊、学习建筑技术，参加一战并取得建筑测量师资格。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】雕塑与建筑训练早于标志性画布实践。 |
| 1922–1927 | 【一手/官方】回 Rosario，在父亲工坊及自己的雕塑工作室从事公共纪念项目。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】委托、尺度与公共空间经验进入早期方法。 |
| 1927–1930 | 【一手/官方】回 Milan，在 Brera 随 Adolfo Wildt 学雕塑；1930 参加 Venice Biennale。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】手工塑形和学院训练与后来反学院动作并存。 |
| 1929–1936 | 【一手/官方】创作《Vittoria fascista》(1929)，1930s 参与多项建筑与公共项目；1934–35 转向非具象雕塑。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【权威二手】政治与形式归属不能用“后来成为先锋”自动抹除；Anthony White 将其置于法西斯与战后大众文化连续语境。[MIT Press](https://mitpress.mit.edu/9780262526159/lucio-fontana/) |
| 1936–1939 | 【一手/官方】在 Albissola 和 Sèvres 深入陶瓷实践，持续与建筑师合作。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】色彩、釉面、火与可塑材料构成后来空间语言的物质底层。 |
| 1940–1946 | 【一手/官方】因 Rosario 国旗纪念碑竞赛回阿根廷，后在多所艺术学校任教；1946 参与创办 Altamira。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】Spatialism 的知识网络是跨大西洋且带有教学/集体讨论性质。 |
| 1946 | 【一手/官方】《Manifiesto Blanco》在 Buenos Aires 形成；Fontana 构想并共同参与，但未签名，由学生群体署名。[UNLP](https://sedici.unlp.edu.ar/handle/10915/185434)；[Guggenheim Bilbao](https://www.guggenheim-bilbao.eus/sabias-que/sabias-que-lucio-fontana) | 【研究推断】作者归属必须分“构想/共同形成”与“文本署名”。 |
| 1947 | 【一手/官方】3 月返意大利；12 月 Fontana、Kaisserlian、Joppolo、Milani 签署第一份空间主义宣言。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】“空间概念”从 Buenos Aires 议程进入 Milan 组织化运动。 |
| 1948 | 【一手/官方】第二份空间主义宣言要求作品走出画框与玻璃罩。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】环境化目标先于著名切口。 |
| 1949 | 【一手/官方】2 月 5 日在 Galleria del Naviglio 创作首个黑光空间环境；同年开始 `Holes`。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】房间与画布两种尺度同步打开。 |
| 1950 | 【一手/官方】`Proposta per un regolamento`；孔洞从旋涡趋向更规则序列。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/)；[《Holes》](https://www.fondazioneluciofontana.it/en/i-buchi-1949-1968/) | 【研究推断】孔由突破动作发展为节奏系统。 |
| 1951 | 【一手/官方】第九届米兰三年展完成大型霓虹结构和间接照明天花；发表技术宣言并签署空间艺术宣言。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】光、建筑、公众路径与理论在同一委托中汇合。 |
| 1952 | 【一手/官方】签署面向电视的空间主义宣言，参与 RAI 早期发光实验。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】时间性媒介和传播系统进入研究。 |
| 1952–1957 | 【一手/官方】发展 `Stones`、`Impastos`、`Baroques`、`Inks`，使用厚色、玻璃、沙、划痕和孔洞。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【权威二手】科学检测确认用料远比“单色水性漆”复杂。[Studies in Conservation](https://www.tandfonline.com/doi/abs/10.1179/2047058411Y.0000000003) |
| 1958 | 【一手/官方】Venice Biennale 展示近期多系列；年末开始 `Slashes`。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【冲突】MoMA 旧标签曾写 1949/1950s 初开始切割；基金会、Guggenheim Bilbao、Pirelli 均指 1958，后者证据一致性更高。[MoMA](https://www.moma.org/collection/works/79874)；[Guggenheim Bilbao](https://www.guggenheim-bilbao.eus/en/exhibition/concepto-espacial-cortes-y-agujeros) |
| 1959 | 【一手/官方】`Slashes` 首次个展展示；开始 `Quanta` 与 `Natura`。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】点变线，同时转向异形组合与三维球体。 |
| 1960 | 【一手/官方】`Natura` 在 Palazzo Grassi 展出；继续环境实验。[同上](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【一手/官方】孔/切在陶土球上成为月面、赤道和手工伤痕。[Centre Pompidou](https://www.centrepompidou.fr/en/ressources/oeuvre/ORE5dEA) |
| 1961 | 【一手/官方】Venice 厚涂玻璃系列后赴 New York 首次美国个展；受 Manhattan 启发转向铜铝 `Metals`；Turin 完成蓝绿霓虹天花。[Guggenheim](https://www.guggenheim.org/exhibition/lucio-fontana-venicenew-york)；[Pirelli 研究册](https://lifa-research.org/site/assets/files/16021/librino_lucio_fontana_eng.pdf) | 【研究推断】地点通过材料和反射进入作品，而非成为插图主题。 |
| 1963–1964 | 【一手/官方】展出 `End of God` 巨大椭圆；发展 `Little Theaters`。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】画框变形，前景框/后场和宇宙卵形扩展边界。 |
| 1964 | 【一手/官方】与 Nanda Vigo 在第十三届米兰三年展完成两件 `Utopie` 环境。[Pirelli 研究册](https://lifa-research.org/site/assets/files/16021/librino_lucio_fontana_eng.pdf) | 【归属要求】必须标注 Vigo 的共同创作及其在后世重建中的执行贡献。 |
| 1966 | 【一手/官方】Walker Art Center 美国大型个展包含新环境；Venice Biennale 与 Carlo Scarpa 合作白色椭圆展室并获绘画奖。[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】切口从单件对象扩展为建筑化观看序列。 |
| 1967 | 【一手/官方】Stedelijk 三件环境、Foligno 环境；发展机械孔洞的 `Ellipses` 与漆金属雕塑。[Pirelli 研究册](https://lifa-research.org/site/assets/files/16021/librino_lucio_fontana_eng.pdf)；[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】徒手、工业精度、单色走廊和荧光错觉并行。 |
| 1968 | 【一手/官方】documenta 4 白色迷宫通向黑切口；年初迁 Comabbio，9 月 7 日卒于 Varese。[Pirelli 研究册](https://lifa-research.org/site/assets/files/16021/librino_lucio_fontana_eng.pdf)；[Fondazione 年表](https://www.fondazioneluciofontana.it/en/lucio-fontana/biografia/) | 【研究推断】最后环境将画布切口放大为观众身体面对的建筑终点。 |

## 1968 年后的档案与重建史（非“艺术家动态”）

- 【权威二手】1972 Palazzo Reale 重建的 1951 霓虹结构尺寸小于后来发现的原始 1:1 图纸，导致多个版本并存问题。[ICOMOS PDF](https://openarchive.icomos.org/id/eprint/2892/1/K046-73.pdf)
- 【一手/官方】1976 黑光环境的纸浆形体由建筑师 Andrea Franchi 在 Fontana 去世后重建，现属基金会；它不是 1949 原构件。[Pirelli 研究册](https://lifa-research.org/site/assets/files/16021/librino_lucio_fontana_eng.pdf)
- 【一手/官方】1982 Teresita Fontana 捐赠的 Foligno 环境重建进入 Castello di Rivoli 收藏。[同上](https://lifa-research.org/site/assets/files/16021/librino_lucio_fontana_eng.pdf)
- 【权威二手】2017–2018 Pirelli HangarBicocca 基于基金会与多机构档案重建多个环境；2019 The Met/El Museo 再采用相关研究成果展示三件环境。[Pirelli 展览页](https://pirellihangarbicocca.org/en/exhibition/lucio-fontana-environments/)；[The Met](https://www.metmuseum.org/exhibitions/listings/2019/lucio-fontana-on-the-threshold)
- 【研究推断】这些节点属于作品接受史和保存史，不能写成 Fontana 本人晚年继续创作的时间线。
