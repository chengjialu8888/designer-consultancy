# Lucio Fontana Phase 1｜去重来源清单

## 统计口径

- 去重使用来源：**26 个**。
- 官方/一手档案、主要博物馆、大学/学术出版社、同行评审技术研究、国际保存机构或权威媒体：**25/26（96.2%）**。
- 其余 1 个为 Mulas 1973 已出版叙述的公开转录入口；它只用于同时代证词，并由 TIME 的独立报道交叉核验，不单独承担核心结论。
- 本清单不含知乎、微信公众号、百度百科、Pinterest、无出处图集、风格聚合博客或 AI 生成介绍。

## 来源冲突索引

1. **首个切割年代**：S03、S09、S16 为 1958；S14 的旧标签写 1949/1950s 初。研究以 1958 为主并保留旧标签冲突。
2. **《Manifiesto Blanco》作者字段**：S07 的目录字段可简化为 Fontana，但正文与 S08 均说明学生署名、Fontana 构想/共同参与。
3. **环境作品“原作”状态**：S09、S21、S22 显示多数原环境已拆除，现有体验多为档案重建；不同版本尺寸和材料可能不一致。
4. **动作照片真实性**：S25 与 S26 均说明《L’Attesa》不是现场真实下刀记录。

## 信息不足与使用边界

- 基金会书信与写作档案没有大规模开放全文，本轮无法系统统计私人通信中的词频、语气和立场变化。
- Carla Lonzi 访谈开放页只有版本研究摘要；未取得校注全文前，不做口语 DNA 定量分析。
- 多数历史环境已毁，重建包含档案解释；任何空间尺寸、色值和材料判断都需绑定具体版本。
- 技术研究覆盖代表性样本而非所有作品，不能把某一材料流程套给每件 `Concetto spaziale`。
