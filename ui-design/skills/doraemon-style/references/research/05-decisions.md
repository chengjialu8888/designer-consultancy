# 05｜媒介选择、工作方法与可观察的创作决策

## 决策 1：把读者年龄写进作品结构

- 【一手/官方｜事实】《哆啦A梦》曾在多个学年誌同时连载，并按年级分别绘写；小学馆大全集后来以读者出生年和升学顺序恢复这种阅读路径。[直接来源](https://www.shogakukan.co.jp/pr/fzenshu/lineup/doraemon/)
- 【研究推断】“儿童视角”不是统一幼龄化。低年级版本需要更直接的表情、动作和单格满足，高年级可增加因果链与概念复杂度；当代设计应先定义认知年龄和阅读节奏。

## 决策 2：让角色色彩回应杂志货架与页面竞争

- 【一手/官方｜事实】作者后来说明蓝色身体、红色项圈、黄色铃铛的组合考虑了学年誌常见红标题、黄背景，目标是使角色醒目。[直接来源](https://dora-world.com/contents/2687)
- 【研究推断】这是媒介情境中的识别优化，而不是抽象色彩心理学。迁移时应先盘点当前界面的背景、邻近品牌与印刷/屏幕限制，再决定主色、轮廓与强调色。

## 决策 3：保留手工彩稿、二色页与薄墨页的媒介差异

- 【一手/官方｜事实】原始彩稿由画笔和颜料完成，保留晕染和涂色不匀；部分作品以二色或薄墨发表。官方彩色作品集明确把原生彩稿与后期数字彩色版区分。[直接来源](https://dora-world.com/contents/2687)
- 【研究推断】后续视觉系统应区分“原稿质感”“历史印刷限制”“现代数字填色”三层，不能用统一饱和色覆盖所有年代，也不能用噪点伪装历史。

## 决策 4：以规则分镜建立安全基线，再让单格承担冲击

- 【权威二手｜解释】研究把规则四段、中小格密度、最低限背景和明确表情视为高效叙事基础；儿童读者又更强烈接收单格瞬间。[直接来源](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf)
- 【研究推断】可执行方法是先固定页面网格与对白格，再把少数“道具初现、空间翻转、后果”格放大或打破背景密度。若每格都奇观化，儿童视角和喜剧节拍都会消失。

## 决策 5：把道具选作故事发动机，而不是未来装饰

- 【一手/官方｜事实】博物馆以秘密道具串联不同故事的多样趣味；官方作品说明也把日常因道具产生意外展开视为基本结构。[直接来源一](https://fujiko-museum.com/exhibition.html) [直接来源二](https://e-comi.shogakukan.co.jp/doraemon)
- 【权威二手｜解释】学术研究将道具解释为愿望具象、身体扩展与后续欲望的发生器。[直接来源](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf)
- 【研究推断】设计新道具前必须写清：原始日常烦恼、单一规则、操作动作、第一次收益、滥用路径、可见代价。外形应从功能和手势生长，不从受保护道具轮廓变体开始。

## 决策 6：让“稍微不可思议”落在日常空间的接缝

- 【一手/官方｜事实】博物馆持续把儿童日常与“Slightly Strange”并列，并以“不可思议的同住者突然进入日常”策展。[直接来源一](https://fujiko-museum.com/english/welcome/) [直接来源二](https://fujiko-museum.com/blog/?p=31894%2F)
- 【一手/官方｜记录转述】后继动画制作人员提到作者曾为“大雄房间”的表现写下细致备忘录，说明普通空间不是可随意替换的空白布景。[直接来源](https://dora-world.com/sp/tvanim_sptalk/vol004.html)
- 【研究推断】科幻事件越大，越要保留一个熟悉参照物和儿童尺度动作；否则会滑向一般太空歌剧或科技概念图。

## 决策 7：从短篇生活喜剧扩展到长篇冒险

- 【一手/官方｜事实】1980年起，《大长篇哆啦A梦》作为剧场动画原作先在《月刊CoroCoro Comic》连载；作者亲自完成的长篇从《大雄的恐龙》延续到第17作。[直接来源](https://www.shogakukan.co.jp/pr/100dora/)
- 【一手/官方｜原话】1982年序言强调不要失去对梦与冒险的憧憬。[直接来源](https://www.shogakukan.co.jp/pr/100dora/)
- 【研究推断】这是尺度转折：角色关系和清楚轮廓保持稳定，环境、旅程和道德风险扩张。长篇化不等于增加细节噪音，而是增加空间层级与连续任务。

## 决策 8：通过下稿、分工、修订控制最终版本

- 【一手/官方｜权威转引】1989年访谈记录了故事/粗略下稿、角色与背景可分工的工作流程。[直接来源](https://macc.bunka.go.jp/1262/)
- 【一手/官方｜事实】博物馆列出从分格对白下绘到勾线、黑块、白色修正、网点的五阶段流程。[直接来源](https://fujiko-museum.com/blog/?p=31800%2F)
- 【权威二手｜档案决策】全集编辑确认作者在单行本化时常加笔修订；编辑以生前最终形态为正文，同时保留初出数据。[直接来源](https://macc.bunka.go.jp/1262/)
- 【研究推断】“简洁”来自多轮控制与修正，不是一次画完。数字设计可对应为：节奏草图 → 轮廓审查 → 黑白层级 → 色块 → 修正痕迹最小化 → 小尺寸测试。

## 决策 9：让原稿可以被近看，同时让印刷页可以被快读

- 【一手/官方｜事实】原画美术书用高于一般印刷物的采集分辨率呈现130余件彩色与黑白原稿，特意展示笔触、墨色、白色修正与铅笔痕。[直接来源](https://dora-world.com/contents/1805)
- 【权威二手｜解释】山口晃指出颜色令黑线更清楚，纸张变化又会转换线条风味。[直接来源](https://bijutsutecho.com/magazine/interview/24161)
- 【研究推断】输出应有双尺度质量门槛：缩小后图形经济，放大后材料可信。任一尺度不能替代另一尺度。

## 决策 10：授权边界优先于“像不像”

- 【一手/官方｜事实】官方使用条款禁止未经许可复制、展示、再发布、传播、修改角色图像与站内资产。[直接来源](https://dora-world.com/terms_en)
- 【研究推断】后续 Skill 必须明确：角色、徽标字形、经典道具、命名、配色组合与独特分镜不可精确复刻；成果只能采用一般性视觉机制，并应避免让公众误认官方授权或联名。
