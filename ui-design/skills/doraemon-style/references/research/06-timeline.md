# 06｜关键时期、作品与方法演化

> 时间线只记录已核验历史和后世档案/展览节点。藤子·F·不二雄于1996年去世，不编造“最近动态”；2021年后的条目是机构对遗产的整理，不是作者的新创作。

| 时间 | 事实与作品 | 可观察的方法意义 | 证据 |
|---|---|---|---|
| 1933 | 【一手/官方】12月1日生于富山县高冈市，本名藤本弘。 | 传记基点，不直接推导视觉风格。 | [博物馆官方传记](https://fujiko-museum.com/english/welcome/) |
| 1944 | 【一手/官方】与转学来的安孙子素雄相识。 | 后来共同投稿与共享笔名的起点；不能据此混同两人的独立作品。 | [博物馆官方传记](https://fujiko-museum.com/english/welcome/) |
| 1951 | 【一手/官方】受手塚治虫影响共同投稿，《天使の玉ちゃん》成为发表出道作。 | 早期视觉谱系中有手塚影响，但成熟《哆啦A梦》不能简化为手塚模仿。 | [博物馆官方传记](https://fujiko-museum.com/english/welcome/) |
| 1954 | 【一手/官方】与安孙子赴东京，入住常盘庄，以藤子不二雄为笔名。 | 进入专业连载与同代漫画网络。 | [博物馆官方传记](https://fujiko-museum.com/english/welcome/) |
| 1961 | 【一手/官方】迁居川崎市生田，此后创作《Q太郎》《飞人》《哆啦A梦》等。 | 儿童日常、稍微不可思议的同住者与简洁角色群逐步成为跨作品结构。 | [博物馆官方传记](https://fujiko-museum.com/english/welcome/) |
| 1969.12 / 1970.01号 | 【一手/官方】《哆啦A梦》在《よいこ》《幼稚園》及小学一年级至四年级等六誌的1970年1月号开始连载；新连载预告见1969年12月号。 | 同时面向不同年龄，促成按年级绘写、直接表情与稳定分镜；彩色角色也需在学年誌版面中醒目。 | [小学馆大全集](https://www.shogakukan.co.jp/pr/fzenshu/lineup/doraemon/) |
| 1970年代初 | 【一手/官方】早期彩稿存在尾巴颜色、手足色与设定差异，角色并非诞生即完全定型。 | 视觉识别是演化结果；不可用成熟模型倒推全部早期页面。 | [官方彩色作品集说明](https://dora-world.com/contents/2687) |
| 1973 | 【权威二手】首个电视动画版播出后短期结束；助手虾原武司回忆其改动原作过多，作者不愿再谈。 | 归属争议节点：动画改编与原作视觉应分开研究；该评价目前仅有单一回忆来源。 | [东洋经济访谈](https://toyokeizai.net/articles/-/262470?display=b) |
| 1974起 | 【一手/官方】瓢虫漫画单行本开始形成作者选编、重排的通行版本；小学馆说明该版由作者选择作品和顺序。 | “经典顺序”是后期编辑决策，不等于初出顺序；版本差异必须标注。 | [小学馆电子配信说明](https://www.shogakukan.co.jp/news/118823) |
| 1979 | 【一手/官方】新的电视动画系列开始，成为长期传播基础。 | 公众熟悉的动画视觉与原作漫画在媒介、团队和年代上不同，不可混为作者单一手笔。 | [神户大学论文的历史梳理](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf) |
| 1980 | 【一手/官方】《大雄的恐龙》开启作者亲自执笔的《大长篇哆啦A梦》系列，并先于电影在《月刊CoroCoro Comic》连载。 | 从生活喜剧扩展到大环境冒险，同时保留普通儿童角色与道具规则。 | [小学馆100年大长篇](https://www.shogakukan.co.jp/pr/100dora/) |
| 1981–1982 | 【一手/官方】《藤子不二雄自选集》出版；1982年第7卷序言留下“不要失去对梦与冒险的憧憬”。 | 作者自选与长篇观念的重要一手节点。 | [小学馆100年大长篇](https://www.shogakukan.co.jp/pr/100dora/) |
| 1987 | 【一手/官方】两人结束搭档关系，藤本改用“藤子·F·不二雄”。 | 署名与归属边界更清楚；此前共同笔名不代表所有作品共同执笔。 | [博物馆官方传记](https://fujiko-museum.com/english/welcome/) |
| 1988–1996 | 【一手/官方】麦原伸太郎进入藤子Pro并任首席助手，晚期在作者指导下参与第17部长篇作画。 | 晚期原稿需要区分作者构思/指导与助手具体作画。 | [官方原画对谈说明](https://dora-world.com/contents/1859) |
| 1994 | 【一手/官方】《小学五年生》25周年访谈留下“把喜欢放在优先位置”的陈述。 | 为兴趣驱动的资料与题材选择提供可追溯一手声音。 | [90周年原画展](https://dora-world.com/contents/3108) |
| 1996.09.23 | 【一手/官方】藤子·F·不二雄去世，62岁。 | 创作时间线终点；之后的动画、电影、商品和展览均属遗产管理或再创作。 | [博物馆官方传记](https://fujiko-museum.com/english/welcome/) |
| 1997 | 【一手/官方】第17部作者系列长篇《大雄的发条都市冒险记》电影化。 | 生前构思与身后完成/发行时间发生交叠，署名需按具体版本核验。 | [小学馆100年大长篇](https://www.shogakukan.co.jp/pr/100dora/) |
| 2009–2013 | 【权威二手】《藤子·F·不二雄大全集》系统刊行；编辑建立全作品年表，记录初出、修订与代笔，并采用作者生前最终形态作为主要正文。 | 现代研究的重要档案基础，也显示“一个最终原版”并不简单存在。 | [MACC前篇](https://macc.bunka.go.jp/1252/) [MACC后篇](https://macc.bunka.go.jp/1262/) |
| 2011 | 【一手/官方】川崎市藤子·F·不二雄博物馆开馆，以原画、工作桌、资料和漫画制作过程为核心。 | 原稿材料、工作环境和视觉过程进入机构保存。 | [博物馆设施说明](https://fujiko-museum.com/english/facilities/) |
| 2021 | 【一手/官方】《THE GENGA ART OF DORAEMON》出版，以圆润、表情、构图、秘密道具等主题放大130余件原稿。 | 官方首次系统把漫画格作为美术原画观看，强化线、墨、修正与材料证据。 | [官方原画美术书说明](https://dora-world.com/contents/1805) |
| 2022 | 【权威二手】新加坡国家博物馆展出70余件来自藤子·F·不二雄博物馆的原稿/草图，并与当代艺术家回应分区。 | 原作档案首次以该规模在日本之外公开；原作与再诠释必须分开。 | [国家博物馆新闻稿](https://www.nhb.gov.sg/nationalmuseum/-/media/nms2024/documents/media-releases/221107-doraemon-exhibition-singapore.pdf) |
| 2023–2024 | 【一手/官方】90周年原画展以“喜欢”为线索展示作者长期兴趣；《藤子·F·不二雄がいた風景》整理访谈、构想笔记、早期原稿和非漫画工作。 | 这是档案再整理，不是作者“近期风格变化”；也暴露开放网页无法覆盖的纸本材料缺口。 | [原画展](https://dora-world.com/contents/3108) [图书说明](https://dora-world.com/contents/3654) |
| 2026 | 【一手/官方】博物馆15周年展以秘密道具及其在不同故事中的多样作用为主题。 | 当代策展继续把道具视为叙事发想核心；不构成作者新作或新立场。 | [博物馆企画展](https://fujiko-museum.com/exhibition.html) |

## 归属与版本注意

- 【研究推断】“藤子不二雄”共同笔名、藤本弘个人创作、助手作画、动画团队改编与藤子Pro后续资产管理是不同层级，视觉研究必须逐项标注。
- 【研究推断】初出学年誌、作者选编单行本、作者修订版、大全集、原始彩稿复刻、数字彩色版、电视动画和电影不能互作无差别证据。
- 【研究推断】本时间线止于可核验档案与机构活动，不将2026展览措辞写成已故作者的“最新观点”。
