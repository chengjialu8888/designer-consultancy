# 03｜视觉表达 DNA

## 总体命题

- 【一手/官方】官方美术原画集以“圆润、脸与表情、构图、秘密道具”等七个主题观看单格原画，并强调笔触、墨色、白色修正与残留铅笔线。[直接来源](https://dora-world.com/contents/1805)
- 【研究推断】视觉语言的核心不是“蓝色圆机器人”，而是：用极经济的轮廓建立可瞬读角色，在规则分镜中把一个具体道具接入日常愿望，再让使用、升级和后果改变身体与空间。

## 构图与分镜

- 【权威二手】神户大学论文援引既有漫画研究，描述藤本弘的基础组织为规则的四段式页面、约8至12格的均质分镜；论文自身在“12格/8格”的转述间存在数字差异，因此本研究只保留“规则四段与中小格密度”这一稳健结论，不把单一格数写成公式。[直接来源](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf)
- 【权威二手】同文指出：对白场景常压低或省略背景，让人物、表情、对白承担信息；场景转换与道具作用需要空间证据时，再恢复房间、街道或空地。[直接来源](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf)
- 【权威二手】对小学生阅读实验的整理显示，年幼读者更集中于“单格本身”和直接表情，而非先整合连续故事；这支持每一格都要有清楚动作、情绪和图地关系。[直接来源](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf)
- 【研究推断】页面节奏可抽象为：日常建立 → 欲望/麻烦 → 道具亮相 → 试用 → 滥用或连锁升级 → 视觉性后果。该结构是叙事机制，不应复制任何具体章节的格位或桥段。

## 圆形几何与角色比例

- 【一手/官方】小学馆把“まるみ（圆润）”列为原画美术研究的独立主题，说明圆形并非外围评论者随意贴上的标签。[直接来源](https://dora-world.com/contents/1805)
- 【权威二手】山口晃细读指出：成熟期头部不是几何正圆，而是前额/面部略鼓、后脑收、重心稍上、鼻部前出、下巴微收；身体由短小曲线连续闭合，形成有内外压力的鼓胀体积。[直接来源](https://bijutsutecho.com/magazine/interview/24161)
- 【权威二手】四肢短粗、关节可在二维动作中灵活“接上”，手脚末端先定，连接段服从姿势可读性而非三维骨骼一致性。大雄等儿童角色常低于标准三头身，眼镜与五官位置随角度服务表情。[直接来源](https://bijutsutecho.com/magazine/interview/24161)
- 【研究推断】可迁移的是“非正圆的受控鼓胀 + 短曲线组件 + 动作优先比例”；不可迁移的是角色的具体头身比、脸部配置、铃铛、口袋、尾巴或标志性剪影。

## 轮廓经济性与线条

- 【权威二手】既有研究把线条概括为排除杂质、功能清楚、不过度自我表现；对白格常以最低背景量突出人物。[直接来源](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf)
- 【一手/官方】原画集说明又强调真实原稿存在细微笔触、墨色浓淡、白色修正和铅笔痕；“经济”不等于矢量无菌或完全均匀。[直接来源](https://dora-world.com/contents/1805)
- 【权威二手】山口晃观察到宽窄有力的镝笔线、短促起落和形随线生的节奏，并转述画集对谈称作者落线较慢。[直接来源](https://bijutsutecho.com/magazine/interview/24161)
- 【研究推断】线条规范应是“少而有压强”：外轮廓稳定、内部线只保留表情/动作所需；允许微小速度差与手工抖动，但不能用随机粗糙滤镜冒充原稿质感。

## 表情、动作与身体

- 【权威二手】小四及以下读者对表情与直接情感表现的理解强于对复杂符号/文字约定的理解，表情因此不是装饰，而是叙事接口。[直接来源](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf)
- 【权威二手】论文指出道具与身体连接后会扩展能力、刷新欲望，甚至造成变形、分解或失控；结尾格常把后果直接交给身体和表情。[直接来源](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf)
- 【研究推断】动作设计先明确“谁想要什么、道具改变了哪一项身体/空间规则、代价落在哪里”，再画姿势；不要先画一个可爱角色再随意摆表情。

## 道具叙事

- 【一手/官方】博物馆将秘密道具视为《哆啦A梦》多样故事与发想力的核心展览对象，而非静态产品目录。[直接来源](https://fujiko-museum.com/exhibition.html)
- 【权威二手】学术分析把道具视为愿望的具象化、身体扩展与新愿望生成器；科学教育研究也发现抽象“能量”常通过可拿取、储存、消耗、转化的日常物体与动作变得具体。[直接来源一](https://da.lib.kobe-u.ac.jp/da/kernel/81003944/81003944.pdf) [直接来源二](https://www.jstage.jst.go.jp/article/jsser/37/2/37_No_2_220203/_pdf/-char/ja)
- 【研究推断】原创道具应使用“普通物件母体 + 一个可说清的规则变化 + 立即可见的操作 + 逐步放大的副作用”。不得复刻竹蜻蜓、任意门、时光机等受保护造型、名称或功能组合。

## 儿童视角与空间

- 【一手/官方】博物馆把儿童日常、温暖笑料与“稍微不可思议”并列为持续原则；“稍微”意味着奇异从熟悉空间旁边长出，而不是另建一套遥远宏大设定。[直接来源](https://fujiko-museum.com/english/welcome/)
- 【一手/官方】原画展把“突然进入日常生活的稍微不可思议的同住者”作为跨作品主题。[直接来源](https://fujiko-museum.com/blog/?p=31894%2F)
- 【权威二手】山口晃认为部分构图像儿童作画：先给最想画的东西最好位置，形体尽量不重叠、大小接近，却由方向线形成复杂秩序；这是高度训练后的儿童观看，而非幼稚涂鸦。[直接来源](https://bijutsutecho.com/magazine/interview/24161)
- 【研究推断】空间优先使用儿童可掌握的尺度：房间、走廊、书桌、空地、街角、屋顶与近郊。科幻入口应改变这些空间的规则；景观再大，也保留可抓取、可奔跑、可躲藏的尺度参照。

## 日常与科幻的接缝

- 【一手/官方】小学馆将短篇定义为“生活搞笑漫画”，未来道具让日常发生意外展开；博物馆用“Slightly Strange”描述同一接缝。[直接来源一](https://e-comi.shogakukan.co.jp/doraemon) [直接来源二](https://fujiko-museum.com/english/welcome/)
- 【研究推断】接缝通常由一个具体动作完成：打开、戴上、贴住、照射、缩放、穿过。视觉上要让“前一秒的普通物”与“后一秒的新物理规则”同格可比较，而不是靠发光粒子或宏大门户替代规则说明。

## 色彩与材料

- 【一手/官方】原生彩稿不是后期数字上色；角色的蓝/红/黄关系考虑了学年誌红字与黄底的竞争环境。颜料由画笔涂布，保留晕染、涂色不匀、二色印刷与薄墨版本。[直接来源](https://dora-world.com/contents/2687)
- 【权威二手】山口晃观察到彩色会反过来强化黑线，颜料颗粒、半透明水彩的平滑覆盖与厚实黑线共同形成表面。[直接来源](https://bijutsutecho.com/magazine/interview/24161)
- 【研究推断】当代配色先检查轮廓与色块分离，再用有限暖色作动作/焦点；背景宜比角色和道具更低对比。避免把所有界面铺成单一“哆啦蓝”，也不要把手工涂色误做成复古噪点滤镜。

## 节奏、文字与观看距离

- 【权威二手】山口晃指出拟声词的字形、方向与散落物形成页面节奏，文字可以从声音变成构图力量。[直接来源](https://bijutsutecho.com/magazine/interview/24161)
- 【一手/官方】原画集把单格放大为观看对象，证明印刷阅读距离与原画近看会显现两层不同信息：远看是动作/轮廓，近看是笔压/修正/材料。[直接来源](https://dora-world.com/contents/1805)
- 【研究推断】设计应通过两级测试：缩略图能读出角色关系、动作与道具；近看才出现线条和材料细节。不要让近看纹理破坏小尺寸清晰度。
