# 01｜存留文字、创作陈述与理论线索

## 研究边界

- 研究对象是漫画家藤子·F·不二雄（本名藤本弘）及其亲自创作的官方《哆啦A梦》漫画视觉语言，不把“哆啦A梦”称为艺术家，也不把后世动画、商品设计自动归入作者本人手笔。
- 藤子·F·不二雄于1996年去世，公开网页能直接核验的长篇访谈全文很少；本文件以出版社、博物馆保存的短句、访谈书目信息、再版说明和工作记录为 surviving voice/records，不补写不存在的“宣言”。
- 引文只保留支持判断所需的短句；其余均为概述。

## 可核验的本人声音

### 1. “喜欢”先于题材分类

- 【一手/官方】1994年《小学五年生》9月号访谈留下的短句是：“僕は、すべてにおいて『好き』であることを優先させてきました”。官方90周年原画展把这句话与手塚治虫漫画、迪士尼动画、西部片与SF电影、8毫米摄影、落语、铁路模型、UFO、遗迹和恐龙等长期兴趣并列展示。[直接来源](https://dora-world.com/contents/3108)
- 【研究推断】这不是“想画什么就画什么”的任性宣言，而是可观察的素材库工作法：先长期积累真实兴趣与资料，再让道具、场景和冒险从熟悉对象中生长。对当代视觉系统的可迁移部分是“建立可持续的主题资料库”，不是复制恐龙、UFO或具体道具。

### 2. 不放弃儿童的梦与冒险

- 【一手/官方】小学馆在《100年大长篇哆啦A梦》页面重印藤子·F·不二雄1982年《藤子不二雄自选集7》序言短句：“夢や冒険に憧れる心は失ってほしくない。”[直接来源](https://www.shogakukan.co.jp/pr/100dora/)
- 【研究推断】短篇的日常尺度与长篇的远行尺度并非两个互不相干的品牌：前者让孩子能进入，后者把同一组普通孩子推向更大空间。视觉上应保留熟悉身体、熟悉伙伴与可读动作，扩大的是环境与风险，而不是把人物突然写实化或英雄化。

### 3. 色彩是出版环境中的识别决策

- 【一手/官方】官方彩色作品集说明转述作者后来的解释：角色从开始就采用蓝色身体、红色项圈、黄色铃铛，并考虑到红色标题和黄色背景较多的学年杂志环境，使角色在页面上醒目。彩稿在作者指示下以画笔和颜料完成，保留晕染与涂色不匀。[直接来源](https://dora-world.com/contents/2687)
- 【研究推断】颜色的首要作用是“在既有媒介环境中建立图形分离”，不是抽取一套固定品牌色到处套用。高纯度三色关系与黑色轮廓共同工作；手工色差又避免了工业色块的僵硬。

### 4. 先由故事与粗略下稿控制，再分工完成

- 【一手/官方】文化厅委托的 Media Arts Current Contents 文章援引藤子·F·不二雄1989年《オレのまんが道2》访谈：合作作品中由他构思故事、做粗略下稿，再交由藤子不二雄Ⓐ画角色，背景则给助手处理。该段针对合作作品《仙べえ》，不能无条件推广到所有《哆啦A梦》页面。[直接来源](https://macc.bunka.go.jp/1262/)
- 【研究推断】可确认的是“叙事、构图、角色、背景”在制作中可拆分，但关键关系由前期下稿约束。不可据此声称所有线稿都由作者独立完成，亦不可抹去助手劳动。

## 由机构保存的创作原则

- 【一手/官方】博物馆把其长期原则概括为温暖的笑、儿童的日常生活和“稍微不可思议”的科幻，并以原画为核心保存“梦、惊奇、玩心”。这是馆方对作品与档案的综合表述，不等同于逐字作者宣言。[直接来源](https://fujiko-museum.com/english/welcome/)
- 【一手/官方】博物馆保存的漫画制作流程为：分格/对白/下绘、勾线、擦除与黑块、白色修正与网点、完成。[直接来源](https://fujiko-museum.com/blog/?p=31800%2F)
- 【一手/官方】小学馆全集按读者出生年份与升学顺序重编，是因为原作曾在多个学年誌同时连载并按年级分别绘写；作者选编的瓢虫漫画版又重新选择并排列篇目。[直接来源](https://www.shogakukan.co.jp/pr/fzenshu/lineup/doraemon/)

## 长文与理论材料的存留情况

- 【一手/官方】《藤子·F·不二雄がいた風景》收录1994年25周年访谈、作品构想笔记、早期原稿、学年誌插画和SF小说装帧等，但网页只提供内容说明，未公开全文。本轮只把它作为“材料确实存在”的目录证据，不把未读内容当作已核验观点。[直接来源](https://dora-world.com/contents/3654)
- 【权威二手】国立国会图书馆记录了1998年《本の窓》“素顔の藤子・F・不二雄”访谈/回忆文章（藤本正子、川本三郎，页2–11），正文仅馆内公开。本轮不能提取原话。[直接来源](https://ndlsearch.ndl.go.jp/books/R000000004-I4415159)
- 【研究推断】现有开放网络证据足以支持媒介、受众与视觉结构研究，但不足以建立完整的私人美学理论；后续 Phase 2 若要提炼“作者理论”，应优先查阅上述纸本/馆内材料，而非用网络名言替代。

## 不应越界的结论

- 不能把馆方“温暖目光”解释成作者从不描绘恐惧、欲望或惩罚；学术研究显示许多结尾仍保留身体失控和情感冲击。
- 不能把“喜欢”简化为题材堆砌；真正可观察的是兴趣、资料、道具功能与叙事后果的结合。
- 不能把出版色彩决策升级成永恒色值规范；原始彩稿还包含二色页、薄墨页、手工晕染及年代差异。
