# Lucian Freud Phase 1 去重来源清单

## 统计口径

- **去重来源总数：30。** 同一机构的不同页面在承担不同证据功能（档案、展览、作品、技术资料）时分别计数；同一页面在多个研究文件中重复引用只计一次。
- **严格口径的官方/一手或权威机构来源：27/30（90%）。** 计入艺术家档案、国家/主要博物馆、Royal Collection、同行评议期刊、学术出版社，以及有明确身份和原始记录的直接参与者出版物/采访。
- **补充来源：3/30（10%）。** Sotheby’s 的 Dawson 访谈和 Acquavella 转载的 *Times* 画室报道因平台有商业利益而降一级；*The New Yorker* 的归属调查为高质量长篇媒体，但不是档案/学术鉴定机构。三者只用于直接见证和争议结构，不单独支撑形式定论。
- **排除项：** 未使用知乎、微信公众号、百度百科、Pinterest、无出处图片集、AI 风格介绍、聚合博客或不可追溯金句。

## 来源间的关键冲突

1. **Cremnitz white 时间与作用**：S10 给出 1975 年采用和具体用法；S16 记录供应与购买；S19 指出缺乏全作品科学检测，反对把风格变化单因归结为铅白。
2. **凝视是残酷还是照料**：S23 代表“残酷线条/暴露”的机构语言；S10 同时保存剥削批评和对 Bowery 系列的亲密、协作、照料重读；S24 提供 Tilley 自己的肯定经验。
3. **姿势自然还是受控**：S22 记录 Freud 声称少强加，但也禁止阅读；S25 强调少摆布；S24 记录姿势的真实疼痛。结论只能是协商与权力并存。
4. **从眼前工作还是空间虚构**：S05 支持“只画眼前”；S10 证明具体室内可把未同时在场的人物拼接为虚构空间。
5. **归属由谁决定**：S26 中本人否认、材料相似、AI 概率、provenance 与 estate 权威彼此冲突；本研究不裁决真伪。

## 当前信息不足

- Gowing 1982 与 Auping 2009–2011 访谈完整逐字稿未在已核验公开网页中取得；只使用博物馆明确摘引。
- 2025 油画 catalogue raisonné 的 Jacob Simon 技术章节已确认存在，但本轮没有获得 74–112 页全文；材料细节以 NPG 摘要、ICON 课程说明和 2023 图录为限。
- 缺少覆盖多件油画的公开 XRF、截面、binder 与层序数据；铅白、底层和上光的作品级分布仍不完整。
- 多数模特没有像 Gayford、Dawson、Bowery、Tilley 那样留下可公开核验的长证词；报酬、休息、撤回权和发表同意的信息不系统。
- 书信档案在线多为目录摘要且集中在 1951 年以前，不能据此重建成熟期完整理论。
