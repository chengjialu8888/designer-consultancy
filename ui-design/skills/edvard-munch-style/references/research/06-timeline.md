# Edvard Munch：工作、母题、版本与展示时间线

## 使用说明

- 【研究推断】时间线优先记录对视觉方法有影响的节点，不追求完整传记。
- 【研究推断】日期带 `约`、`?` 或范围时保持原有不确定性；“构想、首次成组、命名、连续布展”分开记录。

## 1863–1889：经验、训练与《病孩》突破

| 日期 | 事件 | 方法意义 |
|---|---|---|
| 1863 | 【一手/官方】12 月 12 日出生于 Løten。[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】传记起点，不推导风格。 |
| 1868 | 【一手/官方】母亲 Laura 因结核病去世，Munch 五岁。[同上](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】疾病和照护语境的事实层。 |
| 1877 | 【一手/官方】姐姐 Sophie 十五岁时死于结核病。[MUNCH：The Sick Child](https://www.munch.no/en/our-collection/the-sick-child/) | 【研究推断】后来《病孩》的记忆来源之一，但实际模特另有 Betzy Nilsen。 |
| 1880 | 【一手/官方】决定成为画家并进入皇家艺术与设计学校。[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】主动训练而非纯传记决定论。 |
| 1885–86 | 【一手/官方】首版《The Sick Child》反复刮改并于 1886 年展出，引起赞扬与强烈批评。[MUNCH：The Sick Child](https://www.munch.no/en/our-collection/the-sick-child/) | 【研究推断】删改、表面痕迹和记忆作画成为长期方法。 |
| 1888–89 | 【一手/官方】Munch 晚年称《生命饰带》最早松散草图始于此时。[MM UT 23](https://emunch.no/TRANS_HYBRIDMM_UT0023.xhtml) | 【研究推断】这是回顾性起点主张，不等同已形成正式系列。 |

## 1889–1902：从 Saint-Cloud 构想到连续饰带

| 日期 | 事件 | 方法意义 |
|---|---|---|
| 1889 | 【一手/官方】在 Kristiania 自办个展、获巴黎奖学金；父亲去世后移居 Saint-Cloud。[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】自主展示与“现代心灵生活”构想并行。 |
| 1890–91 | 【一手/官方】Munch 记述《Kiss》、“yellow boat”、《Street?》《Man and Woman》《Angst》等于此期完成。[MM UT 23](https://emunch.no/TRANS_HYBRIDMM_UT0023.xhtml) | 【研究推断】母题群先于稳定总题名。 |
| 1891 | 【一手/官方】进行点彩与短笔触实验，同时认为印象主义不足以表达内在状态。[MM N 122](https://www.emunch.no/TRANS_HYBRIDMM_N0122.xhtml) | 【研究推断】转向不是抛弃全部早期技术，而是重新编入表达体系。 |
| 1892 | 【一手/官方】相关图像首次在 Kristiania 成组展出；柏林个展一周后关闭。[MM UT 23](https://emunch.no/TRANS_HYBRIDMM_UT0023.xhtml)、[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】争议促使更强的系列说明与展示策略。 |
| 1892 | 【一手/官方】日记形成后来《The Scream》的散文诗文本，写到血红天空、朋友继续前行和穿过自然的无尽呐喊。[Nasjonalmuseet：The Scream](https://www.nasjonalmuseet.no/en/collection/object/NG.M.00939) | 【研究推断】文本、记忆与图像版本共同生成母题。 |
| 1893 | 【一手/官方】《Vampire》《The Scream》《Madonna》等扩展系列，并在 Unter den Linden 私人空间作为自主饰带展示。[MM UT 23](https://emunch.no/TRANS_HYBRIDMM_UT0023.xhtml) | 【研究推断】母题意义来自扩展和并置。 |
| 1893 | 【一手/官方】国家博物馆《The Scream》绘画版完成；另有约 1893 粉彩版。[Nasjonalmuseet](https://www.nasjonalmuseet.no/en/collection/object/NG.M.00939) | 【研究推断】“1893 的《呐喊》”仍包含多个物件和背面草图。 |
| 1894 | 【一手/官方】开始系统版画实践；《病孩》有干刻版。[MUNCH：The Sick Child](https://www.munch.no/en/our-collection/the-sick-child/) | 【研究推断】母题进入可重印、可变版材。 |
| 1895 | 【一手/官方】《The Scream》石版完成，另有签名日期 1895 的粉彩版。[Nasjonalmuseet](https://www.nasjonalmuseet.no/en/collection/object/NG.M.00939) | 【研究推断】黑白传播版本与彩色独件共同塑造公众图像。 |
| 1896 | 【一手/官方】《病孩》石版以最多六块石版进行不同颜色组合，并有手工加色实例。[MUNCH：The Sick Child](https://www.munch.no/en/our-collection/the-sick-child/) | 【研究推断】同版多色不是次级复制，而是表情范围实验。 |
| 1896–97 | 【权威二手】为 Ibsen 戏剧制作节目图像；舞台经验逐渐进入空间构图。[Musée d’Orsay](https://www.musee-orsay.fr/en/program/whats-on/exhibitions/presentation/edvard-munch-poem-life-love-and-death) | 【研究推断】封闭空间、人物走位和观众关系成为形式资源。 |
| 1897 | 【权威二手】版画开始与绘画在展览话语中平等出现。[Musée d’Orsay](https://www.musee-orsay.fr/en/program/whats-on/exhibitions/presentation/edvard-munch-poem-life-love-and-death) | 【研究推断】系列从单一媒介转为跨媒介网络。 |
| 1898–1917 | 【权威二手】《Two People. The Lonely Ones》木刻在长期印制中形成多色与构图变体。[MoMA](https://www.moma.org/collection/works/72085) | 【研究推断】版材是跨年工作的存储器。 |
| 1899–1900 | 【一手/官方】《The Dance of Life》早期主要版本完成。[Nasjonalmuseet](https://www.nasjonalmuseet.no/en/collection/object/NG.M.00941) | 【研究推断】之后 1925 年再画，体现母题跨期回返。 |
| 1902 | 【一手/官方】柏林分离派前厅形成连续环绕饰带，主题覆盖现代心灵生活。[MM UT 23](https://emunch.no/TRANS_HYBRIDMM_UT0023.xhtml) | 【研究推断】这是《生命饰带》作为展示系统的关键节点，不是唯一“完成日”。 |

## 1902–1916：舞台、治疗与纪念尺度

| 日期 | 事件 | 方法意义 |
|---|---|---|
| 1902 | 【一手/官方】与 Tulla Larsen 的关系在枪击事件后结束，Munch 手部受伤；同时继续重整工作方向。[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】事件进入后续自我叙事，但不能单因解释全部作品。 |
| 1905–34 | 【一手/官方】长期使用胶版复制法，MUNCH 藏 506 张、约 100 个母题。[MUNCH：Hectographs](https://www.munch.no/en/our-collection/edvard-munchs-hectographs/) | 【研究推断】廉价、直接的复制技术也被当作实验工具。 |
| 1906 前后 | 【权威二手】与 Max Reinhardt 的 Kammerspiele 合作 Ibsen 戏剧，舞台与封闭室内影响“Green Room”组画。[Musée d’Orsay](https://www.musee-orsay.fr/en/program/whats-on/exhibitions/presentation/edvard-munch-poem-life-love-and-death) | 【研究推断】不稳定透视获得具体剧场语境。 |
| 1908 | 【一手/官方】主动请求进入 Daniel Jacobson 的私人诊所并停留数月。[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】是生活和工作条件转折，不是风格病因学分期。 |
| 1909–16 | 【一手/官方】为奥斯陆大学礼堂制作大型装饰，《The Sun》约 1910–11。[同上](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】波线、放射和色场转入纪念性公共空间。 |
| 约 1910 或更晚 | 【一手/官方】MUNCH 的《The Scream》绘画版通常标 `1910?`；国家博物馆称不早于 1910。[Nasjonalmuseet](https://www.nasjonalmuseet.no/en/collection/object/NG.M.00939) | 【研究推断】必须保留日期问号。 |

## 1916–1944：Ekely、旧母题新场所与遗赠

| 日期 | 事件 | 方法意义 |
|---|---|---|
| 1916 | 【一手/官方】购入 Ekely，建设多个画室，持续处理园景、劳动者、动物和自画像。[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】晚期并非只剩焦虑题材；工作基础设施支持并行项目。 |
| 1918 | 【一手/官方】为 Blomqvist 展览出版《The Frieze of Life》说明，回顾约三十年构想与展示史。[MM UT 23](https://emunch.no/TRANS_HYBRIDMM_UT0023.xhtml) | 【研究推断】属于晚年自我解释，应与早期记录交叉读。 |
| 1922 | 【一手/官方】把《生命饰带》母题改造成 Freia 工厂十二幅大型墙画。[MUNCH：Monumental art at Ekely](https://www.munch.no/en/edvard-munch/ekely/monumental-art-at-ekely/) | 【研究推断】系列随建筑、尺度和公共观众重构。 |
| 1925 | 【一手/官方】再次绘制《The Dance of Life》。[MUNCH：Monumental art at Ekely](https://www.munch.no/en/edvard-munch/ekely/monumental-art-at-ekely/) | 【研究推断】二十多年后的回返不是复制早期版本。 |
| 约 1926–27 | 【一手/官方】《病孩》第六/末个绘画版本；正文签年 1926、图注 1927，在线资料存在年份差异。[MUNCH：The Sick Child](https://www.munch.no/en/our-collection/the-sick-child/) | 【研究推断】对象级使用需保留范围并核对藏品号。 |
| 1928 左右 | 【一手/官方】《The Origins of the Frieze of Life》整理早期方法，详述《病孩》删改、波线和版本。[MM UT 13](https://www.emunch.no/TRANSMM_UT0013.xhtml) | 【研究推断】重要方法文本，同时具有回顾性重构风险。 |
| 1933–40 | 【一手/官方】给 Thiis、Romdahl 等的信稿继续讨论波线、功能主义、版本递进和饰带计划。[MM N 43](https://www.emunch.no/TRANS_HYBRIDMM_N0043.xhtml)、[Musée d’Orsay](https://www.musee-orsay.fr/en/program/whats-on/exhibitions/presentation/edvard-munch-poem-life-love-and-death) | 【研究推断】旧母题仍在被解释和规划。 |
| 1940 | 【一手/官方】德军占领后修改遗嘱，把几乎全部作品留给奥斯陆市。[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】大量版本、版材与文献作为整体过程保存。 |
| 1940–43 | 【权威二手】《Self-Portrait between the Clock and the Bed》把老年身体置于钟、床与自身作品之间。[The Met](https://www.metmuseum.org/exhibitions/listings/2017/edvard-munch) | 【研究推断】晚期仍以空间关系处理时间、死亡与艺术遗产。 |
| 1944 | 【一手/官方】1 月 23 日在 Ekely 去世。[MUNCH 时间线](https://www.munch.no/en/edvard-munch/edvard-munch-timeline/) | 【研究推断】时间线终点。 |

## 版本与日期冲突速查

- 【一手/官方】**《The Scream》**：1893 绘画；约 1893 粉彩；1895 粉彩；1895 石版；第二绘画版 `不早于 1910/1910?`；1893 绘画背面另有草图。[Nasjonalmuseet](https://www.nasjonalmuseet.no/en/collection/object/NG.M.00939)
- 【一手/官方】**《The Sick Child》**：六个绘画版本从 1885–86 延续至约 1926–27；另有 1894 干刻、1896 石版和多种手工加色/组合印次。[MUNCH](https://www.munch.no/en/our-collection/the-sick-child/)
- 【权威二手】**《Two People. The Lonely Ones》**：对象日期可写 1899/1917 或 1899–1917，约 100 张并含色彩与构图变体。[MoMA](https://www.moma.org/collection/works/72085)
- 【一手/官方】**《生命饰带》**：1888–89 松散草图（晚年回忆）；1892 首次成组；1893 扩展自主饰带；1902 连续环绕布展；1918/1919 展览说明；之后仍继续重画和建筑化。[MM UT 23](https://emunch.no/TRANS_HYBRIDMM_UT0023.xhtml)、[Musée d’Orsay](https://www.musee-orsay.fr/en/program/whats-on/exhibitions/presentation/edvard-munch-poem-life-love-and-death)

## 时间线不足

- 【研究推断】本轮没有逐件核对完整绘画与版画 catalogue raisonné，故不提供所有版本的绝对数量和状态号。
- 【研究推断】Munch 晚年文字常重新安排早期影响与起点；“他说何时开始”与“作品/展览记录何时可见”均保留。
