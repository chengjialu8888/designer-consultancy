# Contemporary Exhibition Editorial

This example captures the visual system used for an AI weekly report about the shift from static web text to real work traces.

## Reference Composition

```text
ARCHIVE                  WORKFLOW RECORDER
static web strips   →    ask → plan → tool → fail → revise → verify → deliver

evidence rail: source / number / consequence
```

The frame is intentionally closer to an exhibition wall than a dashboard: a large proposition, one readable mechanism, and a small number of traceable signals.

## Reference Tokens

- Canvas: `#E8E5DC` paper or `#0E0F0D` black
- Ink: `#171814`
- Signal: `#D9FF3F` acid yellow
- Friction: `#FF5B3F` red
- Judgment: `#3159FF` cobalt blue
- Scale: `#FFB338` orange
- Master ratio: `16:9`
- Desktop safe area: `48px`
- Feishu display target: `980 × 552px`

## What This Example Teaches

1. A report becomes more memorable when the visual makes a system relationship visible.
2. Evidence cards should be adjacent and labeled, not hidden in a decorative dashboard.
3. A work trajectory carries more meaning than a pile of isolated metrics when the story is about how an agent completes a task.
4. Contemporary-art influence works best as composition, scale, material, and viewing condition, not as imitation of a named artist.
